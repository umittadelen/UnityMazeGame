<h1>🌸 Features</h1>

- Customizable maze sizes
- 3D environments

<h1>🌸 Download</h1>

Download the latest release from the [Releases](https://github.com/umittadelen/UnityMazeGame/releases) tab.

1. Download the `.7z` file
2. Extract it
3. Run `MazeRunner.exe`

<h1>🌸 Controls</h1>

| Action | Key |
|--------|-----|
| Move Forward | W |
| Move Backward | S |
| Move Left | A |
| Move Right | D |
| Jump | Space |
| Look | Mouse |
| Pointer | Alt |
